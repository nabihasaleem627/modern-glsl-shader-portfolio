## 🎨 How the Shader Works

The fragment shader (`src/shaders/aurora.frag`) runs once per pixel on the GPU each frame. Here's a simplified walkthrough:

### 1. UV Coordinate Normalization
```glsl
vec2 uv = gl_FragCoord.xy / u_resolution.xy;
```
`gl_FragCoord` gives the pixel's position in screen-space pixels. Dividing by the canvas resolution maps it to `[0, 1]` on both axes — a standard UV space where `(0,0)` is bottom-left and `(1,1)` is top-right.

### 2. Aspect-Ratio Correction
```glsl
float aspect = u_resolution.x / u_resolution.y;
vec2 p = uv;
p.x *= aspect;
```
Without correction, noise patterns on wide viewports look stretched horizontally. Multiplying `p.x` by the aspect ratio makes the noise cells square regardless of window shape.

### 3. Mouse Influence (`u_mouse`)
```glsl
vec2 mouseEffect = (u_mouse - 0.5) * 0.12;
p += mouseEffect;
```
The mouse position is passed in as a `[0, 1]` vector. Subtracting `0.5` centres it so the shader offsets left/right/up/down as the cursor moves. The factor `0.12` keeps the effect gentle — a soft parallax rather than a jarring shift.

### 4. Time-Based Animation (`u_time`)
```glsl
float t = u_time * 0.18;
```
`u_time` is elapsed seconds since the page loaded. Scaling it down to `0.18×` keeps the aurora drift slow and meditative. This value is threaded into the noise function so the flow field evolves over time.

### 5. Flow / Noise Calculations
The shader uses three layers:

**Value Noise** (`noise()`): Interpolates random values at grid cell corners using smoothstep easing, producing smooth organic blobs.

**Fractal Brownian Motion** (`fbm()`): Sums 5 octaves of noise at increasing frequencies. Each octave adds finer detail at half the amplitude of the previous one — producing natural-looking cloud/plasma structure.

**Domain Warping** (`warpedNoise()`): Distorts the input UV using two independent `fbm` calls before the final `fbm` evaluation. This is Inigo Quilez's technique — the result is the distinctive curling, folding, aurora-like flow that cannot be achieved with simple noise.

### 6. Color Generation
Four anchor colours (deep indigo, violet, electric purple, subtle blue) are blended using `mix()` and `smoothstep()` based on the noise field value and the vertical UV position. This creates tonal variation from cool (top) to warm (bottom) matching the aurora aesthetic.

### 7. Grain Effect
```glsl
float grainSeed = dot(gl_FragCoord.xy, vec2(12.9898, 78.233)) + u_time * 0.5;
float grain = fract(sin(grainSeed) * 43758.5453) - 0.5;
col += grain * 0.028;
```
A classic hash-based pseudo-random grain is added at the pixel level. The `u_time` component makes it animate (dithering) rather than static, giving the image a film-like organic texture. The `0.028` scale keeps it subtle.

### 8. Final Output
```glsl
gl_FragColor = vec4(clamp(col, 0.0, 1.0), 1.0);
```
The colour is clamped to prevent over-bright artefacts, then output as a fully opaque RGBA value. The canvas sits behind all HTML content.

## ⚡ Performance Decisions

| Decision | Reason |
|---|---|
| Cap DPR at `Math.min(devicePixelRatio, 2)` | Prevents 3× or 4× pixel counts on modern phones from overwhelming the GPU |
| Page Visibility API | Stops the `requestAnimationFrame` loop when the tab is hidden — zero GPU usage when not visible |
| `alpha: false` WebGL context | Removes per-frame alpha compositing overhead |
| `antialias: false` | Not needed for a full-screen procedural effect |
| `depth: false, stencil: false` | No depth buffer allocated — the shader only needs colour |
| 5 `fbm` octaves (not 8+) | Good visual quality with reasonable fragment shader cost on mid-range GPUs |
| Uniform location caching | `gl.getUniformLocation()` called once at setup, not per frame |
| `IntersectionObserver` for nav and reveals | No scroll-event listeners polling on every scroll tick |

## ♿ Reduced-Motion Fallback

When `@media (prefers-reduced-motion: reduce)` matches (the user has enabled "Reduce Motion" in their OS accessibility settings):

1. The WebGL canvas is **not rendered at all** — the `requestAnimationFrame` loop never starts.
2. A **static CSS gradient** using the same purple/indigo palette is displayed instead.
3. All CSS transitions are reduced to near-zero duration.
4. The hero content remains fully readable and visually consistent.

This respects the WCAG 2.1 guideline (2.3.3 — Animation from Interactions) and ensures the portfolio is usable for people with vestibular or motion sensitivity disorders.

---

## 🔧 Reduced-Motion Implementation

```jsx
// In App.jsx — detected once and passed down
const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

// In ShaderHero.jsx
if (prefersReducedMotion) return; // skip WebGL init entirely

// CSS — always shown if no canvas
.hero-gradient-fallback.visible { display: block; }
```

## 🚀 Deployment

Because the build output is a **single self-contained HTML file**, deployment is simple:

### Netlify
1. Drag and drop `dist/index.html` to [netlify.com/drop](https://netlify.com/drop), **or**
2. Connect your GitHub repository and set build command `npm run build` and publish directory `dist`.

### Vercel
```bash
npx vercel --prod
```

### GitHub Pages
1. Build the project: `npm run build`
2. Copy `dist/index.html` to the `gh-pages` branch or docs folder
3. Enable GitHub Pages in repository settings

### Any Static Host
Upload `dist/index.html` — no server-side runtime is required.
